Punched To Go

Ludum Dare 60 (48h) - Theme : Old Tech

My submission for the LD60 gmejam. I had 48h to make this game. I made a mini retro game playable on an old punched cards machine.

Key points

  • Unity
  • Game Jam
  • Made in 48h

Game Jam page Play the game

Theme : Old Tech

I though of using Punched Cards somehow for this theme, as it's a fascinating piece of tech that also happens to be very flexible with what you can do with them. I ended up using them to send inputs to a pretty classic retro mini game. Holes in the cards would count as 1 in binary, so then I could map anything I wanted to those punched binary values.

Mini Game

Because there were so many ways to toy with binary values hidden behind a mysterious punch system, I though of making the mini game itself be a puzzle game. To progress, you would have to figure out how to use the punches on the card in new ways everytime (eg. you have to realize that the binary values can map to an asccii like code for the alphabet, so that you can say things in game).

Punching the Cards

As I designed the cards to have 12x5 holes, I wanted to avoid having 60 items to fill in the holes. Instead I made all the hole fillers a single object, and clip out part of the objects based on a 12x5 texture (one pixel per hole). When I draw black onto the texture at this pixel, the pixels of the hole filler object is clipped (discarded), when I draw red it displays a highlighted version, and when I draw white it displays the basic albedo.

Results

I managed to make the game I wanted to make, just a little bit harder even tho I tried to make it as easy as possible.
